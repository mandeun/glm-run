# glm-run

**GLM 에게 일을 맡기고, 그 말을 안 믿고, 검사기로 확인하는 스크립트 한 장.**

Claude Code 를 GLM(z.ai)으로 돌려 프롬프트 한 장을 통째로 맡깁니다.
끝나면 GLM 의 «다 됐습니다»를 무시하고, 여러분이 정한 검사 명령을 다시 돌려
**기계가 통과라고 할 때만** 통과라고 말합니다. 실패하면 되돌리는 명령을 찍어 줍니다.

## 원리 — 처음 보는 사람용

Claude Code 는 두 조각입니다.

- **손** — 내 컴퓨터에서 파일을 고치고 명령을 돌리는 프로그램 (`claude`)
- **머리** — 인터넷 저쪽에서 «이렇게 고쳐»라고 답하는 AI

손이 머리에게 **전화를 겁니다.** 그 전화번호가 `ANTHROPIC_BASE_URL` 입니다.
번호만 z.ai 로 바꿔 걸면 **손은 그대로인데 대답하는 머리만 GLM 으로 바뀝니다.**
새 프로그램을 까는 게 아니라 전화번호를 바꾸는 것뿐입니다.

그리고 사람과 GLM 은 서로 말을 주고받지 않습니다. **같은 폴더를 씁니다.**
쪽지(프롬프트 파일)를 놓고 → GLM 을 그 폴더에서 깨우고 → GLM 이 파일을 고쳐 놓으면
→ 검사기가 채점합니다. 교대 근무와 같습니다.

핵심은 **믿지 않는 것**입니다. AI 는 «통과했습니다»라고 말할 수 있지만
`glm-gates.txt` 에 적힌 명령은 기분이 없습니다. 통과의 정의를 사람이 미리 적어 둡니다.

## 하는 일 — 다섯 단계

```
① 지금 초록불?  → ② 스냅샷  → ③ GLM 실행  → ④ 다시 검사  → ⑤ 빨간불이면 되돌리는 법
```

1. **시작부터 빨간 줄이면 멈춥니다.** 안 그러면 GLM 탓인지 원래 그랬는지 구분이 안 됩니다.
2. **스냅샷을 뜹니다.** git 저장소가 아니어도 되돌릴 수 있게 `.glm/snapshots/` 에 tar 로 떠 둡니다.
3. **`claude -p` 헤드리스로 GLM 을 부릅니다.** 쓸 수 있는 도구는 스크립트 위쪽 `ALLOWED` 목록뿐입니다.
   `rm` · `curl` · `git push` 는 목록에 없어서 못 합니다.
4. **검사기를 다시 돌립니다.** GLM 의 말이 아니라 이 결과가 판정입니다.
5. **기록을 남긴 뒤에** 결과를 말합니다. 저장 전에 찍는 성공은 거짓말이라서요.

`.glm/runs/<시각>/` 에 GLM 출력 · 검사 로그 · 바뀐 파일 목록이 남습니다.

## 쓰기

**1) 키 저장 (딱 한 번)** — 키는 코드에도 저장소에도 적지 않습니다. 홈 밑 파일 하나에만 둡니다.

```bash
mkdir -p ~/.config/glm
cat > ~/.config/glm/env <<'ENV'
export ANTHROPIC_AUTH_TOKEN=여기에_받은_키
export GLM_BASE_URL=https://api.z.ai/api/anthropic
export GLM_MODEL=glm-5.3
ENV
chmod 600 ~/.config/glm/env
```

키 발급: <https://z.ai/manage-apikey/apikey-list>
(`GLM_ENV_FILE` 환경변수로 다른 위치를 쓸 수 있습니다.)

**2) 통과의 정의를 적기** — 일할 폴더에 `glm-gates.txt` 를 만듭니다.

```
python3 -m pytest -q
node --check index.js
```

**이 파일이 없으면 스크립트는 시작하지 않습니다.** 검사가 없으면 GLM 이 뭘 망쳐도 모르니까요.

**3) 시키기**

```bash
./glm-run.sh 프롬프트.md --dry-run   # GLM 을 안 부르고 절차만 확인
./glm-run.sh 프롬프트.md             # 진짜 시킵니다 (할당량이 나갑니다)
```

## 확인한 것

이 스크립트가 진짜 잡는지 **일부러 망가뜨려 확인했습니다.** 「통과했다」만 보고 믿지 않으려고요.

| 해본 것 | 결과 |
|---|---|
| 정상 상태 dry-run | 5단계 전부 OK, 종료코드 0 |
| 3단계에서 규칙 파일을 망가뜨림 | 4단계 검사가 **실패**로 잡음, 종료코드 1 |
| 안내대로 tar 로 되돌리기 | 파일 원상복구, 검사 다시 전부 OK |
| `glm-gates.txt` 없는 폴더 | 시작 거부, 종료코드 1 |

## 안 하는 것

- 커밋·푸시를 하지 않습니다. 스냅샷은 `.glm/` 안 tar 뿐입니다.
- GLM 과 대화를 주고받지 않습니다. 프롬프트 한 장을 넘기고 결과를 받는 단발입니다.
- 요금·할당량을 계산해 주지 않습니다. z.ai 요금은 직접 확인하세요.

## 한계

- `--permission-mode acceptEdits` 로 돕니다. GLM 이 폴더 안 파일을 **묻지 않고 고칩니다.**
  그래서 2단계 스냅샷이 있는 것이고, 남에게 보여 줄 수 없는 폴더에서는 쓰지 마세요.
- 접속 주소·모델명은 2026-09-01 에 <https://docs.z.ai/devpack/tool/claude> 에서 확인한 값입니다.
  바뀔 수 있습니다. 바뀌면 `~/.config/glm/env` 한 곳만 고치면 됩니다.
